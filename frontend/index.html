Theory of Computation Academic Reference & Viva Voce Guide Secondary Section • Viva Q&A

Concise reference covering formal definitions, algorithm time and space complexities, project-specific architecture, and likely viva voce questions.

1. Core Formal Definitions (Alphabet, String, Language, DFA & NFA) +

Alphabet (Σ): A finite, non-empty set of symbols. Here Σ = {A, T, G, C}.

Kleene Star (Σ*): The set of all finite strings over Σ, including the empty string ε.

NFA: 5-tuple M = (Q, Σ, δ, q0, F) where δ: Q × (Σ ∪ {ε}) → 2^Q.

DFA: 5-tuple M = (Q, Σ, δ, q0, F) where δ: Q × Σ → Q. Deterministic, exactly one transition per symbol.

2. Why use DFAs for DNA Pattern Matching instead of standard string search? +
Once a DFA is synthesized from a pattern P (or regular expression R), recognizing any input DNA sequence of length N takes strictly O(N) linear time regardless of pattern length. Each nucleotide requires exactly one transition lookup in hardware or memory with zero backtracking, guaranteeing deterministic throughput across large genome databases.

Subset Construction O(2^k × |Σ|) worst case, O(k) for DNA patterns O(2^k) states worst case

4. Likely Viva Voce Questions & Answers +

Q1: How do you handle overlapping pattern matches (e.g. ATAT in ATATAT)?
Answer: The pattern-matching NFA recognizes Σ*P. When converted to a DFA, states preserve the longest matching prefix of the pattern upon each transition (similar to KMP). An accepting state is reached each time an occurrence finishes, naturally capturing overlapping occurrences.

Q2: What is the role of ε-closure in Subset Construction?
Answer: It computes all states reachable without consuming input symbols. The initial DFA state is S0 = ε-closure(q0), and each target state is ε-closure(Move(U, a)).

Q3: How is a mutation classified as a substitution vs insertion/deletion?
Answer: In Needleman-Wunsch alignment, mismatched paired nucleotides indicate substitutions (SNPs). A gap character '-' in the reference sequence indicates an insertion in the candidate, while '-' in the candidate indicates a deletion.
