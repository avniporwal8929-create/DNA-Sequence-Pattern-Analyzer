Theory of Computation Academic Reference & Viva Voce Guide Comprehensive Revision

Conceptual fundamentals explained with bioinformatics examples, designed for second-year engineering students and academic evaluation.

1. What is an Alphabet (Σ) in Formal Language Theory? +
An alphabet is a finite, non-empty set of symbols. In this project, the DNA alphabet is formally defined as:
Σ = {A, T, G, C} where each symbol denotes one of the four nitrogenous nucleotides (Adenine, Thymine, Guanine, Cytosine).
2. What is a String and Formal Language? +
A string (or word) is a finite sequence of symbols chosen from an alphabet Σ. For example, w = ATGCG is a string of length |w| = 5 over Σ = {A, T, G, C}.
The set of all possible strings over Σ, including the empty string ε, is denoted by the Kleene star closure Σ*.
A formal language L is any subset of Σ* (i.e., L ⊆ Σ*). For example, the language of all DNA sequences starting with a start codon is L = { w ∈ Σ* | w starts with ATG }.
3. What is a Non-Deterministic Finite Automaton (NFA)? +
An NFA is a 5-tuple M = (Q, Σ, δ, q0, F):
  • Q: Finite set of states.
  • Σ: Alphabet of input symbols.
  • δ: Transition function mapping Q × (Σ ∪ {ε}) → 2^Q (power set of states).
  • q0 ∈ Q: Initial start state.
  • F ⊆ Q: Set of final or accepting states.
In an NFA, for a given state and input symbol, there may be zero, one, or multiple transitions, and transitions may occur without consuming input (ε-transitions).
4. What is a Deterministic Finite Automaton (DFA)? +
A DFA is also a 5-tuple M = (Q, Σ, δ, q0, F), but with two strict constraints:
  • The transition function δ maps Q × Σ → Q. For every state and input symbol, there is exactly one next state.
  • No ε-transitions are permitted.
DFAs are deterministic and can be directly implemented in hardware and software for O(N) linear time pattern matching!
5. What is ε-Closure and the Move Function? +
ε-Closure: For a state s, ε-closure(s) is the set of all states reachable from s by following zero or more ε-transitions. For a set of states T:
ε-closure(T) = ⋃_{s ∈ T} ε-closure(s).

Move Function: For a state set T and symbol a ∈ Σ:
Move(T, a) = ⋃_{s ∈ T} δ(s, a).
6. How does the Subset Construction (Rabin-Scott) Algorithm work? +
The Subset Construction algorithm converts an NFA into an equivalent DFA:
  1. Initial DFA State: S0 = ε-closure(q0). Add S0 to an unmarked queue.
  2. Loop: While there are unmarked DFA states U:
    • For each nucleotide symbol a ∈ {A, T, G, C}:
    • Compute V = ε-closure(Move(U, a)).
    • If V is not in the set of DFA states and is non-empty, assign it a new DFA state ID and add V to the queue.
    • Add DFA transition: δ_DFA(U, a) = V.
  3. Accepting States: Any DFA state containing at least one NFA final state is an accepting state of the DFA.
7. How is Substring Pattern Search performed with Automata? +
To find all occurrences of pattern P in sequence T: An NFA is constructed recognizing language Σ* P. The initial state has a self-loop on all DNA symbols {A, T, G, C}, allowing the search to begin at any nucleotide position. Converting this NFA to a DFA creates a Knuth-Morris-Pratt style deterministic automaton. Streaming the sequence through the DFA detects every occurrence (including overlapping occurrences) immediately whenever an accepting state is entered!
